# N₂ Hamiltonian at 4.00 Å

This directory contains the all-electron 6-31G Hamiltonian and RHF preparation for the [HBCI calculation](../../all-electron-HBCI/full/R-4.00/README.md). The [geometry](geometry.xyz), [raw output](prepare.out), and [RHF reconstruction check](results.json) accompany the integral archive.

Prepared on spark-6ad0 using Forte2 main commit 692ae30049bebc71d5f1c4dc01f8bbbce596d751, four OpenMP threads, and one OpenBLAS thread.
